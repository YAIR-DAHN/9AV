# ספירה לאחור לסיום צום תשעה באב

## תיאור הפרויקט
מיני אתר המאפשר הצגת ספירה לאחור לזמן סיום צום תשעה באב. האתר מציג את זמני יציאת הצום בערים שונות בישראל, כולל:
- אופקים
- ירושלים
- חיפה
- תל אביב
- באר שבע
- זמן יציאת הצום לפי שיטת רבינו תם

(הזמנים הינם לפי לוח אור החיים)

## קישור לדף
https://yair-dahn.github.io/9AV/

עודכן לשנת תשפ"ה

## טכנולוגיות
האתר פותח באמצעות הטכנולוגיות הבאות:
- **HTML**: מבנה הדף
- **CSS**: עיצוב וסגנון
- **JavaScript**: לוגיקה ותפקוד הספירה לאחור

## תכונות עיקריות
- ספירה לאחור בזמן אמת עד לסיום הצום.
- הצגת זמני יציאת הצום בערים מרכזיות בישראל.
- חישוב זמן יציאת הצום לפי שיטת רבינו תם.

## איך להשתמש
1. הורד או שיבט את הפרויקט למחשב שלך:
   ```bash
   git clone https://github.com/YAIR-DAHN/9AV.git
   ```
2. פתח את הקובץ `index.html` בדפדפן האינטרנט שלך.
